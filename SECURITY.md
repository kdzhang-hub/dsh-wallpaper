# Security policy

## Supported version

Only the latest published release receives security fixes.

## Reporting a vulnerability

Do not post a vulnerability that enables filesystem access, local command
execution, or cross-origin access in a public issue. Report it through the
private security-reporting channel configured for the project's GitHub
repository: https://github.com/kdzhang-hub/dsh-wallpaper/security/advisories/new
If private reporting has not yet been enabled, contact the maintainer through
the repository before disclosing the details publicly.

Include the package version, DSH host version, Windows version, the smallest
reproduction, impact, and any relevant sanitized request/response details. Do
not include wallpaper files, absolute paths, tokens, or personal data.
